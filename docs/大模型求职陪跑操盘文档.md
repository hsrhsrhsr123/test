# 大模型求职陪跑业务操盘文档

| 项目 | 说明 |
| --- | --- |
| 文档目的 | 与 OfferShow 平台对齐合作方案,明确定位、产品、分工与试运行评估标准 |
| 合作双方 | 甲方:基座小登R(百度大模型算法工程师,小红书 1275 粉丝);乙方:OfferShow 平台 |
| 合作模式 | 甲方负责销售+内容,乙方负责导流+交付人员支持;分成 7:3(甲方 7) |
| 业务现状 | 副业已跑通,累计收入 5.2 万,验证了客单价与交付模式 |
| 试运行周期 | 2 个月(自签约日起) |

## 一、市场定位

### 1.1 目标客户画像(按阶段分层)

| 客群 | 画像 | 核心痛点 | 付费意愿 |
| --- | --- | --- | --- |
| 实习陪跑 | 硕士在读(计算机/AI 相关),目标大模型算法/工程实习 | 无项目经历、简历空、不了解大模型岗位真实要求 | 中,家庭付费为主 |
| 社招陪跑 | 1-5 年经验工程师(后端/传统算法/数据),想转型大模型方向 | 技术栈断层、不知如何包装已有经验、面试八股与实战脱节 | 高,自付,决策快 |
| 本科+海外背景 | 海外院校本科/硕士,回国求职大模型岗 | 信息差大(不了解国内招聘节奏)、缺国内实习、时差沟通难 | 最高,对结果敏感 |

### 1.2 竞品分析

| 竞品类型 | 代表 | 价格带 | 优势 | 短板 |
| --- | --- | --- | --- | --- |
| 大机构求职服务 | 职徒、UniCareer 类 | 1.5-5 万 | 品牌、销售体系成熟 | 导师非一线在职,大模型方向内容陈旧,交付标准化但不深 |
| 平台型内容社区 | 牛客、面试鸭类 | 0-几百元 | 流量大、面经多 | 无 1v1 交付,不解决个体问题 |
| 个人 IP 导师 | 各平台在职工程师单干 | 3000-8000 | 一线经验、真实 | 无交付团队,精力有限,服务不稳定,无平台背书 |
| 低价录播课 | B站/知乎付费课 | 99-999 | 便宜 | 完课率低,无反馈闭环 |

### 1.3 差异化优势

1. **一线在职背书**:主理人为百度大模型算法工程师,内容与面试标准来自当前一线,而非二手资料;
2. **IP + 平台双引擎**:个人 IP 提供信任与转化,OfferShow 提供流量补给与交付人力,解决个人导师"服务不稳定"的通病;
3. **垂直聚焦**:只做大模型方向,不做泛求职,简历、项目、面试题库全部围绕 LLM 岗位构建;
4. **低门槛筛选漏斗**:99 元知识星球承接观望用户,降低信任成本,再向高客单价陪跑转化。

## 二、产品与定价

### 2.1 服务分层与交付标准(服务周期均为 3 个月)

| 项目 | 实习陪跑 | 社招陪跑 | 本科+海外背景 |
| --- | --- | --- | --- |
| 定价 | 4000-6000 | 6000-10000 | 8000-12000 |
| 1v1 沟通 | 每周 1 次(45-60 分钟) | 每周 1 次(60 分钟) | 每周 1 次(60 分钟,时差协调) |
| 日常答疑 | 微信工作日 24h 内回复 | 微信工作日 12h 内回复 | 微信工作日 12h 内回复 |
| 简历迭代 | 不限次,保底 3 轮深度打磨 | 不限次,保底 5 轮深度打磨 | 不限次,保底 5 轮深度打磨 |
| 项目辅导 | 1 个大模型实战项目梳理 | 1-2 个项目重构+技术栈补齐规划 | 1-2 个项目 + 国内求职节奏规划 |
| 模拟面试 | 3 次(含复盘报告) | 5 次(含复盘报告) | 5 次(含复盘报告) |
| 附加权益 | 面经库 + 岗位内推信息同步 | 面经库 + 谈薪辅导 1 次 | 面经库 + 谈薪辅导 1 次 + 时区灵活排期 |

> 定价在区间内浮动依据:目标公司梯队、基础水平评估(首次免费诊断后报价)。

### 2.2 交付红线

- 所有承诺次数为**保底值**,上不封顶但以 3 个月周期为限;
- 不承诺"保 offer",销售话术与合同中统一表述为"提升竞争力与面试通过率";
- 每位学员建立交付档案(沟通记录、简历版本、模面评分),作为服务凭证与投诉仲裁依据。

## 三、获客与转化漏斗

### 3.1 渠道矩阵

| 渠道 | 角色 | 动作 | 责任方 |
| --- | --- | --- | --- |
| 小红书(基座小登R) | 主获客+品牌 | 每周 3-4 篇笔记(面经、行业认知、学员案例),导流私信 | 甲方 |
| OfferShow 小程序 | 流量补给 | 广告投放 → 用户匹配 → 移交甲方销售转化 | 乙方 |
| 微信私域 | 转化+维护 | 1v1 咨询、免费诊断、成交、售后 | 甲方 |
| 知识星球(99 元/人) | 筛选池 | 面经库+每周答疑,筛出高意向用户向陪跑转化 | 甲方运营 |

### 3.2 转化路径与目标转化率(试运行期假设,跑数后修正)

```
小红书曝光 / OfferShow 匹配
        │  私信/留资 → 加微信        (线索获取)
        ▼
微信 1v1 咨询 + 免费简历诊断         (咨询→诊断 ≥ 60%)
        ▼
方案报价                             (诊断→成交 ≥ 25%)
        ▼
付费陪跑(4000-12000)
        ▲
知识星球(99 元)── 星球→陪跑转化 ≥ 10%
```

试运行期获客目标:小红书月均新增线索 ≥ 40 条,OfferShow 月均移交有效线索 ≥ 20 条,知识星球累计 ≥ 100 人。

## 四、合作分工

### 4.1 职责边界

| 模块 | 甲方(基座小登R) | 乙方(OfferShow) |
| --- | --- | --- |
| 内容生产 | ✅ 全部小红书/星球内容 | 提供素材支持(岗位数据、薪资数据) |
| 获客 | 小红书自然流量 | ✅ 小程序广告投放与用户匹配 |
| 销售转化 | ✅ 全部 1v1 咨询与成交 | — |
| 交付 | 主导交付方案,承接核心 1v1 | ✅ 提供交付人员(模面官/简历顾问)并管理 |
| 财务 | 核对流水 | ✅ 收款、流水管理、按月结算 |
| 品牌 | ✅ 个人 IP 建设 | 平台背书、联合宣传 |

### 4.2 分成与结算

- 分成比例:**甲方 70% / 乙方 30%**,按实收金额(扣除退款后)计算;
- 结算周期:自然月结,每月 5 日前乙方出具上月流水对账单,10 日前完成打款;
- 退款发生时,已结算部分按比例在下月结算中冲抵。

### 4.3 沟通机制

- **每 3-5 天**微信群同步一次:线索量、跟进中客户、交付进展、风险预警;
- 每 2 周一次线上复盘会(30 分钟):核对漏斗数据,调整投放与内容策略;
- 交付人员变动、价格调整、退款决策,须双方确认后执行。

## 五、风险与底线

### 5.1 客户投诉处理流程

1. **24 小时内响应**:甲方为第一接口人,先安抚并记录诉求;
2. **48 小时内定责**:依据交付档案判定属销售预期管理问题(甲方责)或交付质量问题(乙方责);
3. **72 小时内给方案**:补偿方案(加课/更换交付人员/部分退款)由责任方主导、双方确认;
4. 重大投诉(涉及公开差评、平台举报)当日拉群处理,暂停该学员分成结算直至解决。

### 5.2 退款机制(按服务进度阶梯退款)

| 阶段 | 退款比例 |
| --- | --- |
| 付费后 7 天内且未开始 1v1 服务 | 全额退款 |
| 服务开始后第 1 个月内 | 退 60% |
| 第 2 个月内 | 退 30% |
| 第 3 个月起 | 不退,可转为等值模面/咨询次数 |

> 退款规则写入服务协议并在成交前明确告知;退款由乙方财务通道执行,分成同步冲抵。

### 5.3 合规底线

- 对外宣传不使用雇主公司名义站台,不泄露任何公司内部信息,不承诺内推必过;
- 不承诺保 offer、不代面试、不提供面试作弊类服务;
- 学员资料仅用于交付,双方均不得外泄或用于其他商业用途。

### 5.4 试运行评估标准(2 个月后复盘)

| 指标 | 达标线 | 数据来源 |
| --- | --- | --- |
| 签约学员数 | ≥ 8 人 | 成交记录 |
| GMV | ≥ 6 万 | 乙方流水 |
| OfferShow 导流成单 | ≥ 3 单 | 线索归因 |
| 退款率 | ≤ 10% | 财务对账 |
| 学员满意度 | ≥ 4.5 / 5 | 月度回访问卷 |
| 交付事故(升级投诉) | 0 起 | 投诉记录 |

**决策规则**:全部达标 → 签订 12 个月正式合作协议;核心指标(GMV、退款率)达标但其余未达 → 延长试运行 1 个月并针对性整改;GMV 或退款率不达标 → 终止合作,按已交付进度完成存量学员服务后结清。
