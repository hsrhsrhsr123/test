# 打砖块 Breakout 🎮

一个纯前端、零依赖的经典打砖块游戏,单个 HTML 文件即可运行。

## 玩法

直接用浏览器打开 `index.html` 即可开始。

- **移动挡板**:鼠标 / 手指拖动,或键盘 `←` `→`
- **发射小球**:点击画面 或 按 `空格`
- **暂停**:`空格` / `P`
- 击碎所有砖块即可过关,难度会随关卡逐渐提升。

## 特性

- 🧱 多关卡,砖块拥有生命值(颜色越亮血越多),关卡越高砖块越硬、布局有随机缺口
- 🎁 掉落道具:**宽**(挡板加宽)、**×3**(三球齐发)、**慢**(小球减速)、**♥**(+1 生命)
- 💥 击碎砖块的粒子特效与光晕小球
- 🏆 本地保存最高分(localStorage)
- 📱 支持鼠标、键盘、触屏三种操作
- 挡板反弹角度取决于击球点,可以自己控制球路

祝你玩得开心!
